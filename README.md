# Elétrons e Estrelas

Engenharia Elétrica e Física explicadas por uma estudante.

Site: https://niinacanteiro.github.io/eletrons-e-estrelas/

## Acessibilidade

O site busca seguir as WCAG 2.2, nível AA:

- Atalho "Pular para o conteúdo", navegação completa pelo teclado e foco sempre visível.
- Botão de acessibilidade (canto inferior esquerdo) com: tamanho do texto, alto contraste, fonte para dislexia (Atkinson Hyperlegible), links sublinhados, texto espaçado, pausa das animações e leitura em voz alta em português. As escolhas ficam salvas no navegador.
- Tradução para Libras com o VLibras (gov.br).
- Respeita as preferências do aparelho de reduzir movimento e aumentar contraste.

Arquivos: `acessibilidade.css` e `acessibilidade.js` (JavaScript puro, sem dependências).
